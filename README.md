# Del Código a la Nube · Programación en la nube

Parcial 2 · Desarrollo de Software V · Universidad Tecnológica de Panamá.

Sitio web educativo y completo sobre **Programación en la Nube (Cloud Computing)**, hecho con HTML, CSS y JavaScript propios (sin plantillas ni frameworks de estilos).

## Páginas
- `index.html`: inicio, definición, mapa del sitio e historia.
- `fundamentos.html`: características, virtualización, regiones, responsabilidad compartida, glosario con buscador.
- `modelos.html`: IaaS, PaaS, SaaS, serverless y modelos de despliegue.
- `proveedores.html`: AWS, Azure, Google Cloud y tabla de equivalencias.
- `practica.html`: código serverless, Docker, Terraform, seguridad y simulador de elasticidad.
- `quiz.html`: quiz interactivo de 8 preguntas.
- `creador.html`: reseña del creador y aplicación de Nielsen y Shneiderman.

## Estructura
```
CSS/      estilos propios
JS/       scripts (main, elasticidad, quiz)
IMG/   imágenes JPG y recursos
```
