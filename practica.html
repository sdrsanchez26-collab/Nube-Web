1. Una función serverless

Esta función responde a una petición HTTP. No hay servidor que administrar y solo se paga cuando alguien la invoca.

Python · AWS Lambda (handler.py) 
import json

def lambda_handler(event, context):
    # Lee el parámetro ?nombre=... de la URL (si existe)
    params = event.get("queryStringParameters") or {}
    nombre = params.get("nombre", "mundo")

    return {
        "statusCode": 200,
        "headers": {"Content-Type": "application/json"},
        "body": json.dumps({"mensaje": f"Hola, {nombre}, desde la nube"}),
    }

2. Un contenedor con Docker

Un contenedor garantiza que tu aplicación corra igual en tu portátil y en cualquier nube.

Dockerfile 
# Imagen base ligera con un servidor web
FROM nginx:alpine

# Copia los archivos de tu sitio al directorio público
COPY . /usr/share/nginx/html

EXPOSE 80
Terminal 
docker build -t mi-sitio .
docker run -d -p 8080:80 mi-sitio
# Abre http://localhost:8080 en tu navegador

3. Infraestructura como código

En vez de crear recursos con clics, los describes en archivos. Así puedes revisarlos, versionarlos y repetirlos.

Terraform · infraestructura como código 
terraform {
  required_providers {
    aws = { source = "hashicorp/aws" }
  }
}

provider "aws" {
  region = "us-east-1"
}

# Un bucket de almacenamiento definido en texto, versionable en Git
resource "aws_s3_bucket" "sitio" {
  bucket = "mi-sitio-demo-12345"
  tags   = { proyecto = "parcial-2" }
}

Código

PASO 2

Pruebas

Se ejecutan pruebas automáticas.

PASO 3

Construcción

PASO 4

Despliegue

Seguridad

Lista de verificación mínima

Identidad y acceso

  • Activa MFA en todas las cuentas.
  • No uses la cuenta raíz para el trabajo diario.
  • Aplica el principio de mínimo privilegio.
  • Nunca subas llaves o contraseñas a Git.

Datos y red

  • Cifra los datos en reposo y en tránsito (HTTPS).
  • No expongas almacenamiento ni bases de datos al público.
  • Activa registros y alertas.
  • Haz copias de seguridad y pruébalas.
